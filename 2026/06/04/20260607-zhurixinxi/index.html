好牧人主日信息（2026年6月7日）

发表于 2026-06-04 分类于 主日信息

一、主日敬拜单: 20260607-主日敬拜单

二、主日证道信息:

证道经文：加拉太书2:1-10
证道题目：众使徒同证——就这一个福音
证道大纲：
    一、捍卫因信称义的福音（1-2）
    二、捍卫使人自由的福音（3-5）
    三、见证合而为一的福音（6-10）

三、主日敬拜诗歌:

诗歌一：万福泉源歌

1.全能上帝，万福泉源，
恳求垂听我赞美。
上帝恩典似水长流，
我们高声颂恩惠。
愿主教我唱诗和谐，
犹如天使颂主前。
上帝恩典实无穷尽，
主的慈爱不变迁。

2.我的一生有主引导，
时时刻刻蒙主恩。
只求上帝永不离我，
直到进入天家门。
有时如羊迷失正路，
主如牧者来找寻。
救我脱离一切危险，
为我流血舍性命。

3.救主洪恩实在高深，
万分之中难报一。
慈悲救主恳求助我，
侍奉上帝尽我力。
我深知道我心软弱，
容易离开我上帝。
今将身心献为活祭，
恳求收纳莫丢弃。阿们。

诗歌二：歌颂救赎主

1.我要歌颂我救赎主，
歌颂祂奇妙大爱；
被钉十架受辱受苦，
为要将我赎出来。
(副歌)
歌颂，歌颂我救赎主，
为救赎我宝血流，
十字架上担我刑罚，
偿我罪债使自由。

2.我要传述奇妙经过，
祂已代赎我罪愆；
慈爱怜悯，无限广阔，
神将我罪尽赦免。
(副歌)
歌颂，歌颂我救赎主，
为救赎我宝血流，
十字架上担我刑罚，
偿我罪债使自由。

3.我要赞美我救赎主，
传祂得胜大权能；
胜过罪恶，摧毁阴间，
胜过罪、死，赐永生。
(副歌)
歌颂，歌颂我救赎主，
为救赎我宝血流，
十字架上担我刑罚，
偿我罪债使自由。

4.我要歌颂我救赎主，
天来妙爱祂赏赐；
使我重生得享天福，
与祂同作神后嗣。
(副歌)
歌颂，歌颂我救赎主，
为救赎我宝血流，
十字架上担我刑罚，
偿我罪债使自由。

诗歌三：今要主自己歌

1.前要的是祝福，今要主自己；
前要的是医治，今惟主而已；
前我贪求恩赐，今要赐恩者；
前我寻求能力，今要全能者。
(副歌)
永远举起耶稣，赞美主不息，
一切在耶稣里，主是我一切。

2.前常用手拉主，今主手牵我；
前常无所适从，今抛锚稳妥；
前要的是感觉，今凭主口说；
前是频频苦试，今完全信托。
(副歌)
永远举起耶稣，赞美主不息，
一切在耶稣里，主是我一切。

3.前是忙于打算，今则靠祈求；
前是悬切挂虑，今主担我忧；
前随我之所欲，今听主支配；
前不住地求讨，今不断赞美。
(副歌)
永远举起耶稣，赞美主不息，
一切在耶稣里，主是我一切。

4.前我欲利用主，今则主用我；
前藉自己作工，今靠主工作；
前欲得人称赞，今求主欢喜；
我所有的一切，都在主自己。
(副歌)
永远举起耶稣，赞美主不息，
一切在耶稣里，主是我一切。（阿们）

回应诗歌：惟独耶稣歌

1.惟独耶稣是我信息，
我所讲论就是耶稣；
永远高举耶稣基督，
我所仰望就是耶稣。
(副歌)
惟独耶稣，永远耶稣，
我心赞美，我口传扬，
救我医我，使我成圣，
荣耀救主，再来之王。

2.惟独耶稣是我救主，
一切罪愆为我担负；
我得称义全靠耶稣，
赐我力量日日侍主。
(副歌)
惟独耶稣，永远耶稣，
我心赞美，我口传扬，
救我医我，使我成圣，
荣耀救主，再来之王。

3.惟独耶稣使我成圣，
除我旧人，诸罪洗清；
真理圣灵充满我心，
表彰基督丰富生命。
(副歌)
惟独耶稣，永远耶稣，
我心赞美，我口传扬，
救我医我，使我成圣，
荣耀救主，再来之王。

4.惟独耶稣，再临君王，
等候主来号筒之声；
接我升天，荣耀盼望，
惟独耶稣，永生真神。
(副歌)
惟独耶稣，永远耶稣，
我心赞美，我口传扬，
救我医我，使我成圣，
荣耀救主，再来之王。阿们。

圣餐诗歌：我们照你恩惠话语

1.我们照祢恩惠话语，
带着谦卑心意，
受死的主，我们会聚，
现今来记念祢。

2.祢的身体为我裂开，
要成我的供给，
我今举起立约杯来，
为的是记念祢。

3.能否我忘客西马尼，
或看祢的孤寂、
祢的血汗和祢哭泣，
而不来记念祢？

4.当我转眼看十字架，
看祢在髑髅地，
神的羔羊，我的救法，
我必须记念祢。

5.记念祢，和祢的苦痛，
和祢对我爱意，
一息尚存，一脉尚动，
我必定记念祢。

6.当我渐衰，嘴唇无音，
思想、记忆软弱，
当祢在祢国度降临，
主，求祢记念我。
